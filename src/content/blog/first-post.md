## Hello, world
I'm Thomas, and I'm building a website. For my entire career I've been working on embedded systems in the aerospace industry. I think I'm pretty slick with C++, but I have very little knowledge of web development. I have a few goals for this project:
- Impress potential employers with some fun/cool things I've built
- Learn about web development technologies I'm unfamiliar with
- Have fun

## Tech stack
Knowing very little of web development, I did what any developer would do to choose a tech stack for my website. I asked Claude. Claude made several suggestions depending on my preferences and use case, with its top pick being Astro, TypeScript, and Tailwind CSS, using Cloudflare for hosting. After doing some research of my own I decided to follow that advice, but I certainly might change things in the future. The idea of learning a more popular framework like React or Svelte does sound appealing, but I think I agree with Claude that Astro fits my use case. It's performant and lightweight, and it's been very easy to use so far. If you want to know more about how I'm building this, check it out on [github](https://github.com/thomasdoesstuff/website). Maybe by the time you click that link I'll have gone mad and rewritten the entire thing in raw HTML and JavaScript, who knows?

## Dev environment
I'm a bit of a nomad at this point as far as dev environments go. VS Code has mildly irritated me one too many times, but I haven't learned emacs yet. Right now I'm just using classic vim at home. If I had to speculate on where I'll end up, I'd say I'm going to make a solid attempt at learning emacs and then get distracted by neovim halfway through and stick with that. For personal projects like this I do my development on my EndeavourOS desktop and Arch Linux laptop. If you haven't heard of EndeavourOS, it's Arch Linux-based and I highly recommend it.

Thanks for being here, and for your patience while I keep working on this website.
